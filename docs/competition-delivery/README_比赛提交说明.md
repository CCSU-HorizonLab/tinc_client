# TincLink 比赛提交说明

## 项目简介

TincLink 是面向跨域设备互联的虚拟网络部署与管理平台。系统由 Spring Boot/RuoYi 管理服务、Vue 2 管理端、Vue 3 + Tauri 桌面端和 Rust Agent 组成，目标是把 Tinc 的配置下载、公钥交换、虚拟网卡设置、进程守护、精确路由和连通诊断收敛到可视化流程中。

本交付为 `v1.0-competition-2026-rc1` 候选版。自动化测试和开发机联调已有证据，但干净 Windows 全流程验收尚未完成，因此当前安装包只能用于验收，不能标记为最终提交版。

## 目录

- `TincLink_完整源代码/`：服务端、管理端、桌面端、Agent、脚本、构建说明与无敏感信息的配置样例。
- `TincLink_可安装软件/Windows客户端/`：Windows 安装候选包、安装说明和 SHA-256。
- `TincLink_可安装软件/服务端部署/`：当前源码构建的 JAR、配置样例、systemd、Nginx 与初始化 SQL。
- `TincLink_可安装软件/Web管理端/`：生产构建产物及部署说明。
- `TincLink_可安装软件/VERSION_AND_HASH/`：版本、提交号和全部交付产物哈希。
- `TEST_REPORT.md`：自动化、实机证据与未验证项。
- `RELEASE_MANIFEST.txt`：版本清单和边界声明。

## 推荐评审顺序

1. 先阅读本说明、`TEST_REPORT.md` 和架构材料，了解已验证范围。
2. 方式 A：使用独立的最小权限比赛测试节点，安装 Windows 客户端并连接现有测试网关。不要提供生产管理员账号。
3. 方式 B：按服务端部署说明准备 MySQL、Redis、Tinc 网关，再安装 Windows 客户端。
4. 方式 C：若现场网络不稳定，查看演示视频、测试证据与系统设计说明书，不把录像替代为实时连通结论。
