# 安全模型

## 权限边界

UI 保持普通用户权限。高权限服务只接受七项枚举业务请求，反序列化拒绝未知操作/额外字段，没有任意命令、任意读写或读取私钥接口。Tinc 路径、数据根目录、授权用户和网卡由管理员设置，不能经 IPC 改动。固定程序通过参数数组执行，不拼接 shell。开发模式仅 debug 构建可用，可通过受限实例后缀隔离测试端点；生产端点固定且不接受该覆盖，Debug 服务不可作为生产服务。

Windows Named Pipe DACL 只给 SYSTEM/Administrators 和指定用户，拒绝远程客户端，首次实例必须独占。客户端取得 pipe 服务 PID 并检查进程 TokenUser 为 LocalSystem（debug 为当前用户），避免非系统进程伪造生产服务窃取密码。Linux socket 0600 指定 UID，服务使用 SO_PEERCRED 校验调用者 UID，客户端检查服务 UID=root。用户 SID/UID 不等于按应用签名鉴权：同一授权用户运行的其他进程也可以调用业务接口，这是当前访问模型。

生产设置与服务二进制必须由管理员持有且普通用户不可修改，否则任何安全保证失效。安装脚本设置 ACL/所有权。不要将服务二进制放在用户可写目录中运行高权限服务。

## 凭据

服务地址必须显式带协议；不自动降级、禁止重定向、正常验证 TLS。HTTP 需要用户勾选明确许可。密码不裁剪、不记录，Token 不返回前端、不持久化、不用于子进程参数；logout 清除内存会话。Rust 密码/token 使用 Zeroizing 缩短残留时间；HTTP/JSON/操作系统内部仍可能产生短期副本，不宣称已锁页或完全防止内存取证。前端密码提交后清空，不用 localStorage 存凭据。

RSA 3072 私钥通过 OS RNG 生成，仅保存在受保护目录。密钥工作进程 stdout 只有公钥，stderr 不转发前端，60 秒超时终止。上传只含公钥 host 文本。服务结构化日志只记录固定阶段和经过控制的错误，不记录请求/响应原文、密码、Token、私钥，也不返回原始 Tinc stdout/stderr。日志目前为内存中最近 200 条；服务重启后清空。

## 不可信配置

拒绝绝对路径、盘符、反斜杠、点路径、ADS、符号链接、大小写冲突、保留设备名、任意额外文件。CRC/解压/大小检查失败返回真实错误。仅允许 tinc.conf 与 hosts/<合法名称>；明确拒绝 tinc-up/down、host-up/down、subnet-up/down、解释器设置、PrivateKeyFile、Device、命令/脚本等。配置 Interface 强制替换为管理员指定值。主机 RSA 公钥需 2048–8192 位，禁止私钥内容；Name 必须与登录身份一致。

文件写入限定在新生成目录，提交采用原子索引切换，不覆盖工作目录外文件或旧配置。数据目录必须保持私有，避免本地攻击者制造链接/重解析点。现阶段不支持共享可写数据目录。后端提供的不受支持指令/脚本会导致配置失败，而不会被自动执行。`server_master` 还必须满足唯一 Address、唯一 `/32` Subnet、至多一个 Port 和完整 PKCS#1 RSA 公钥；客户端 host 必须绑定登录返回的精确 `node_ip/32`。

网卡残留恢复记录位于同一受保护数据目录。自动恢复只接受版本正确、无未知字段，并同时精确匹配当前管理员设置的接口/前缀、`active.json` 中地址/generation/profile，以及当前已校验 `server_master` 的单个 `/32` 路由；损坏、缺少有效配置或任一字段不一致时返回 `adapter_state_invalid`，不会按猜测网段、任意地址或任意网卡清理。配置和启动在待清理状态下被拒绝，防止切换配置后误删另一地址或路由。

## 已知限制

- `key/upload` 已要求 sid + Token 的节点绑定，客户端不发送 Authorization Header 或 Cookie，也不回退到旧客户端仅 sid 的不安全请求；真实网关写入与重载仍待验收。
- 后台审批、id/ids、状态上报响应和心跳控制契约未明确，相关操作暂不启用。
- 只验证进程运行，无已验证的隧道连通探测或自动路由；不能推断连接成功。
- 未完成真实系统服务安装、跨用户拒绝、TAP/TUN、网络路径和安装包签名验证前，不应按生产就绪发布。
- 强制终止后的恢复记录与命令构造已有自动测试，但系统命令成功到记录原子落盘之间仍有极短窗口，且尚未在 Windows TAP/Linux TUN 上完成强杀、服务重启和系统重启验收。
- RSA crate 的实现/依赖仍须持续安全审计；固定 lockfile 不等于已通过密码学审计。
- 配置旧版本保留含私钥，卸载默认保留数据，不偷偷删掉用户可用配置；销毁需管理员明确处理。
